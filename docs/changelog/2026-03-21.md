## Tools

### tools/startup-launcher/

C++ launcher (active) and alternative implementations for comparison.

- `cpp/launcher.cpp` + `cpp/build.bat` — C++ launcher source; compiles to `startup-launcher-cpp.exe`. Detects AHK v1/v2, scans `scripts\startup\`, launches all `.ahk`/`.ahk2` files, writes to `startup-launcher.log`.
- `cpp/startup-launcher-cpp.exe` — compiled binary (active, used by test script and Task Scheduler)
- `go/launcher.go` + `go/build.bat` — Go implementation (comparison only)
- `nushell/launcher.nu` — Nushell implementation (comparison only)
- `powershell/launcher.ps1` — PowerShell implementation (comparison only)
- `autohotkey/launcher-basic.ahk2` + `launcher-advanced.ahk2` — AHK self-launching implementations (comparison only)

### tools/process-killer/

- `go/main.go` + `go/build.bat` — Go terminator; compiles to `terminator-go.exe`. Kills all running AutoHotkey processes by name, reports PIDs and execution time. (active)
- `go/terminator-go.exe` — compiled binary (active, used by test script)
- `go/test.bat` — manual test script for the terminator
- `other/terminator.ps1` — PowerShell implementation (comparison only)
- `other/terminator.nu` — Nushell implementation (comparison only)
- `other/terminator.ahk` — AHK implementation (comparison only)
- `other/performance-comparison.bat` — benchmarks all terminator implementations

### tools/monitor/

- `go/src/monitor-enhanced.go` + `go/build.bat` — Enhanced Go monitor; compiles to `monitor-enhanced.exe`. Shows PID, PPID, process name, script file, memory, virtual memory, runtime, status, and privilege (Admin/User) in a table. (active)
- `go/src/monitor.go` — Original Go monitor (simpler output, also compiled)
- `go/exe/monitor-enhanced.exe` — compiled binary (active, used by test script)
- `nushell/monitor.nu` — Nushell implementation (comparison only)
- `powershell/monitor.ps1` — PowerShell implementation (comparison only)
- `python/monitor.py` + `requirements.txt` — Python implementation (comparison only)
- `rust/src/autohotkey-monitor.rs` + `Cargo.toml` — Rust implementation (comparison only)

### tools/task-scheduler/

Scripts to register the `AHK Startup Launcher` scheduled task that runs `startup-launcher-cpp.exe` at logon with highest privileges.

- `setup-startup-launcher-task.bat` — basic batch setup (recommended for first-time use)
- `setup-startup-launcher-task.ps1` — basic PowerShell setup
- `register-startup-launcher-task.bat` — advanced batch setup with `--no-run`, `--debug` flags
- `register-startup-launcher-task.ps1` — advanced PowerShell setup with `-NoRun`, `-Verbose`, `-KeepOpen` flags

### tools/startup-shortcuts-installer/

PowerShell scripts to install `.lnk` shortcuts for startup scripts into the Windows Startup folder.

- `install-automatic.ps1` — auto-installs shortcuts for all scripts in `scripts\startup\`
- `install-automatic-dev.ps1` — dev variant with additional logging and dry-run support
- `install-manual.ps1` — interactive version for selective installation
